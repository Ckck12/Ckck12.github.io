{% comment %} Site-wide language switch (English / Korean / Simplified Chinese). Included in by head/custom.html so is set before the body renders (no flash). Priority: ?lang=en|ko|zh in the URL, then localStorage "cp-site-lang", then English. The buttons live in masthead.html ([data-lang-set]); CSS in _sass/layout/_project.scss. Labels change width on a switch, so renav() makes the greedy nav (jquery.greedy-navigation.js) re-measure: it widens the nav so every link comes back, then restores the width and the menu button (the state of a fresh page load) so links that no longer fit move to the menu. Both steps run synchronously, so nothing is painted in between. compress_html joins all lines in production, so the script must not contain line comments, and it avoids the less-than sign and the double ampersand. {% endcomment %}
