SSituation

  • SimLingo, a CARLA driving VLA, first writes a commentary, then drives conditioned on it.
  • Example: “Decelerate to stay behind the gray car in 22.5 m.” The commentary is meant to make driving interpretable.
  • Its training commentary is auto-generated by rules from privileged simulator state, which knows every actor, visible or not.
  • So a label can name a cause that the generator's own visibility flag marks as not visible.
  • Control is conditioned on the sentence, so such claims enter the control loop.

S상황

  • CARLA 주행 VLA인 SimLingo는 먼저 주석 문장을 쓰고, 그 문장을 조건으로 주행합니다.
  • 예: “22.5 m 앞 회색 차 뒤에 머물도록 감속하라.” 주석은 주행 판단을 해석 가능하게 하려는 장치입니다.
  • 학습용 주석은 규칙 기반 생성기가 특권 시뮬레이터 상태로 자동 생성합니다. 이 상태는 보이든 안 보이든 모든 액터를 압니다.
  • 그래서 라벨이 생성기 자체 가시성 플래그상 “안 보임”인 원인을 언급할 수 있습니다.
  • 제어가 문장에 조건화되어 있으므로, 이런 주장이 제어 루프로 들어갑니다.

S情境

  • SimLingo 是 CARLA 中的驾驶 VLA：先生成一句解说文本，再以该句为条件驾驶。
  • 例如：“减速，保持在 22.5 m 外的灰色车辆后方。”解说的本意是让驾驶决策可解释。
  • 训练用解说由规则生成器基于仿真器特权状态自动生成；该状态掌握所有交通参与者，无论是否可见。
  • 因此，标签可能提到生成器自身可见性标志标为“不可见”的原因。
  • 由于控制以该句为条件，这类表述会进入控制回路。

TTask

  • Measure how often training commentary cites causes its own visibility flag marks as not visible.
  • Test whether that language changes control or is only narration.
  • Find a repair that removes unsupported claims but keeps the driving command.
  • Build closed-loop infrastructure to evaluate fixes in simulation.

T과제

  • 학습 주석이 자체 가시성 플래그상 “안 보임”인 원인을 얼마나 자주 언급하는지 측정.
  • 그 문장이 제어를 바꾸는지, 단순한 해설인지 검증.
  • 근거 없는 주장은 없애되 주행 명령은 남기는 수정 방법 탐색.
  • 시뮬레이션에서 수정 방법을 평가할 폐루프 인프라 구축.

T任务

  • 测量训练解说所述原因被自身可见性标志标为“不可见”的频率。
  • 检验这些语言是在改变控制，还是仅仅是叙述。
  • 寻找修复方法：去掉无依据的表述，同时保留驾驶指令。
  • 搭建闭环基础设施，在仿真中评估修复方法。

AAction

  • Full data audit. Parsed all 2,085,459 commentary records (37 files). Matched each cause clause against the generator's LiDAR point-count visibility flag.
  • Controlled text edits (open-loop). Same camera frames; only the commentary changes. Waypoints are then re-predicted.
    • Swap only the cause clause (2×2 design: verb and cause varied independently).
    • Re-inject identical text as a harness check.
    • Swap one cause attribute with the verb fixed: distance, direction, or colour (control).
    • Confidence intervals: route-level bootstrap.
  • Repair comparison. Delete the sentence vs. rewrite only the cause clause with a hedge (e.g. “… because the situation ahead cannot be fully verified from this view”). Each has a length-matched placebo edit.
  • Closed-loop infrastructure. CARLA 0.9.15 + Bench2Drive (220 routes) on cloud GPU VMs. Diagnosed Vulkan rendering failures in containers; moved to KVM VMs with GPU rendering. Added parallel route runners and a CHAIR hallucination scorer against simulator ground truth.
  • Ongoing method. Designing and evaluating a hazard-belief module. It moves decision-relevant hazard information out of the commentary into a separate belief with a risk map. It is trained by distillation from a teacher that sees the original label.

A행동

  • 데이터 전수 감사. 주석 기록 2,085,459건(37개 파일)을 모두 파싱했습니다. 각 원인절을 생성기의 LiDAR 포인트 수 기반 가시성 플래그와 대조했습니다.
  • 통제된 텍스트 개입 (개루프). 같은 카메라 프레임에서 주석만 바꾸고 웨이포인트를 다시 예측했습니다.
    • 원인절만 교체 (2×2 설계: 동사와 원인을 독립적으로 변경).
    • 같은 문장 재주입으로 실험 장치 점검.
    • 동사 고정, 원인 속성 하나만 교체: 거리, 방향, 색(대조군).
    • 신뢰구간: 경로 단위 부트스트랩.
  • 수정 방법 비교. 문장 통째 삭제 vs 원인절만 헤지로 재작성(예: “… 이 시점에서는 전방 상황을 완전히 확인할 수 없으므로”). 각각 길이를 맞춘 플라세보 편집을 함께 두었습니다.
  • 폐루프 인프라. 클라우드 GPU VM에 CARLA 0.9.15 + Bench2Drive(220개 경로)를 구축했습니다. 컨테이너 안 Vulkan 렌더링 실패를 진단해, GPU 렌더링이 되는 KVM VM으로 옮겼습니다. 병렬 경로 실행기와 시뮬레이터 정답 기반 환각 채점기(CHAIR)를 추가했습니다.
  • 진행 중인 방법. 위험 믿음(hazard-belief) 모듈을 설계·평가 중입니다. 판단에 필요한 위험 정보를 주석 밖으로 빼서, 위험 지도를 가진 별도 믿음으로 옮깁니다. 원래 라벨을 보는 교사 모델로부터 증류로 학습합니다.

A行动

  • 全量数据审查。解析全部 2,085,459 条解说记录（37 个文件），将每个原因从句与生成器基于 LiDAR 点数的可见性标志逐一比对。
  • 受控文本干预（开环）。在同一相机帧上只修改解说文本，再重新预测路径点。
    • 仅替换原因从句（2×2 设计：动词与原因独立变化）。
    • 重新注入相同文本，用于检查实验框架。
    • 固定动词，只替换原因的一个属性：距离、方向或颜色（对照）。
    • 置信区间：路线级 bootstrap。
  • 修复方法对比。整句删除 vs 仅将原因从句改写为不确定表述（如“……因为从当前视角无法完全确认前方情况”），两者各配一组长度匹配的安慰剂编辑。
  • 闭环基础设施。在云 GPU 虚拟机上部署 CARLA 0.9.15 + Bench2Drive（220 条路线）。诊断出容器内 Vulkan 渲染失败，改用支持 GPU 渲染的 KVM 虚拟机解决。另实现并行路线运行器，以及基于仿真器真值的幻觉评分器（CHAIR）。
  • 进行中的方法。正在设计并评估风险信念（hazard-belief）模块：把决策所需的风险信息从解说中移出，放入带风险地图的独立信念表示；以蒸馏方式向能看到原始标签的教师模型学习。

RResult (all open-loop)

  • Flag-mismatched causes are common in some scenarios. 5.48% of cause-bearing records cite a cause the generator's LiDAR visibility flag marks as not visible. Signalized-junction right turns reach 38.1%.
  • Language is a control input, not narration. Swapping only the cause clause shifts predicted speed by +0.85 m/s (95% route-bootstrap CI [0.69, 1.02]; 300 frames / 119 routes; one scenario type). Re-injecting identical text changes it by 0.000.
  • The model reads cause details. Released SimLingo, verb fixed, 204 hidden-hazard braking frames / 93 routes:
    • Cause at 5 m instead of 40 m: predicted speed 0.132 m/s lower [0.078, 0.191].
    • Direction swapped: +0.221 m/s [0.149, 0.311].
    • Colour swapped (control): only +0.015 m/s [0.007, 0.024].
  • Deleting “hallucinations” deletes braking. Deleting unsupported sentences loses braking caution in 40.7% [30.8, 51.4] of hidden-hazard braking frames. Hedging only the cause clause loses 2.5% (204 frames). The gap persists under length-matched placebos, so fix the clause, not the sentence.
  • Closed-loop infrastructure is running; closed-loop results are pending. Manuscript in preparation (target: NAACL).

R결과 (모두 개루프)

  • 플래그와 어긋난 원인 언급은 일부 시나리오에서 흔합니다. 원인 언급 기록의 5.48%가 생성기 LiDAR 가시성 플래그상 “안 보임”인 원인을 언급했습니다. 신호 교차로 우회전에서는 38.1%입니다.
  • 언어는 해설이 아니라 제어 입력입니다. 원인절만 바꿔도 예측 속도가 +0.85 m/s 변했습니다(95% 경로 부트스트랩 신뢰구간 [0.69, 1.02], 300프레임 / 119경로, 단일 시나리오 유형). 같은 문장을 다시 넣으면 변화는 0.000입니다.
  • 모델은 원인의 세부까지 읽습니다. 공개 SimLingo, 동사 고정, 숨은 위험 + 제동 프레임 204개 / 93경로:
    • 원인 거리 40 m 대신 5 m: 예측 속도 0.132 m/s 감소 [0.078, 0.191].
    • 방향 교체: +0.221 m/s [0.149, 0.311].
    • 색 교체(대조군): +0.015 m/s [0.007, 0.024]에 그침.
  • “환각”을 지우면 제동도 지워집니다. 근거 없는 문장을 삭제하면 숨은 위험 + 제동 프레임의 40.7% [30.8, 51.4]에서 제동 조심성이 사라집니다. 원인절만 헤지로 바꾸면 2.5%입니다(204프레임). 길이 맞춤 플라세보에서도 차이가 유지되므로, 문장이 아니라 절을 고쳐야 합니다.
  • 폐루프 인프라는 가동 중이며, 폐루프 결과는 아직 없습니다. 논문 준비 중(목표: NAACL).

R结果 （均为开环）

  • 与标志不符的原因在部分场景中很常见。含原因的记录中有 5.48% 所述原因被生成器的 LiDAR 可见性标志标为“不可见”；信号灯路口右转场景高达 38.1%。
  • 语言是控制输入，而不只是叙述。仅替换原因从句，预测速度变化 +0.85 m/s（95% 路线级 bootstrap 置信区间 [0.69, 1.02]；300 帧 / 119 条路线；单一场景类型）。重新注入相同文本的变化为 0.000。
  • 模型会读取原因的细节。公开发布的 SimLingo，固定动词，204 个隐藏风险制动帧 / 93 条路线：
    • 原因距离由 40 m 改为 5 m：预测速度降低 0.132 m/s [0.078, 0.191]。
    • 交换方向：+0.221 m/s [0.149, 0.311]。
    • 交换颜色（对照）：仅 +0.015 m/s [0.007, 0.024]。
  • 删除“幻觉”也会删除制动。删除无依据句子时，40.7% [30.8, 51.4] 的隐藏风险制动帧失去制动谨慎度；仅改写原因从句时只有 2.5%（204 帧）。长度匹配的安慰剂编辑下差距依然存在，因此应修改从句，而非整句。
  • 闭环基础设施已在运行，闭环结果尚未得出。论文准备中（目标：NAACL）。
